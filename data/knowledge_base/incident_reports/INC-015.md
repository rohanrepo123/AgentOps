# INC-015: Notification provider errors

## Summary
A production incident affected `svc-notification`.

## Root Cause
Provider latency increased and exhausted worker connection pools.

## Resolution
Bound connection pools and add provider timeout alerts.

## Investigation Notes
Correlate logs, service metrics, deployment history, feature flags, database state and the
service-specific runbook. Historical incidents are supporting evidence, not definitive proof.
