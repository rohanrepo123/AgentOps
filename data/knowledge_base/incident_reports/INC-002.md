# INC-002: Elevated API Latency

## Summary
Subscription API requests exceeded normal latency.

## Root Cause
A slow Subscription Service dependency was called synchronously, consuming the API Gateway timeout budget.

## Signals
- API p95: approximately 4.8 seconds
- downstream subscription latency: above 2 seconds
- request timeout errors
- gateway itself not showing corresponding CPU saturation

## Resolution
Introduce bounded downstream timeouts and parallelize independent downstream operations.

See runbook `rb-api-latency`.
