# INC-020: Storage timeout storm

## Summary
A production incident affected `svc-storage`.

## Root Cause
Provider response latency exceeded the client timeout.

## Resolution
Increase bounded timeout within SLA and add circuit breaking.

## Investigation Notes
Correlate logs, service metrics, deployment history, feature flags, database state and the
service-specific runbook. Historical incidents are supporting evidence, not definitive proof.
