# INC-021: Worker retry storm

## Summary
A production incident affected `svc-worker`.

## Root Cause
A permanent validation error was configured as retryable.

## Resolution
Classify permanent errors and send them to a dead-letter queue.

## Investigation Notes
Correlate logs, service metrics, deployment history, feature flags, database state and the
service-specific runbook. Historical incidents are supporting evidence, not definitive proof.
