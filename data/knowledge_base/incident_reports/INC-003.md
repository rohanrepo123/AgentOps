# INC-003: Authentication Failures

## Summary
A subset of users could not log in after signing-key rotation.

## Root Cause
The Authentication Service continued using a stale signing-key cache.

## Evidence
- key rotation event
- stale key cache warning
- token validation failures
- elevated 401 responses

## Resolution
Invalidate stale cache and refresh signing keys automatically.
