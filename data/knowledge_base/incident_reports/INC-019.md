# INC-019: Search query slowdown

## Summary
A production incident affected `svc-search`.

## Root Cause
A high-cardinality query caused expensive index scans.

## Resolution
Add query guards and optimize the affected index.

## Investigation Notes
Correlate logs, service metrics, deployment history, feature flags, database state and the
service-specific runbook. Historical incidents are supporting evidence, not definitive proof.
