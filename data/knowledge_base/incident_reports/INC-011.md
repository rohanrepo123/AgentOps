# INC-011: Auth token refresh spike

## Summary
A production incident affected `svc-auth`.

## Root Cause
A refresh-token dependency became slow, causing retry amplification.

## Resolution
Bound refresh retries and add dependency timeout.

## Investigation Notes
Correlate logs, service metrics, deployment history, feature flags, database state and the
service-specific runbook. Historical incidents are supporting evidence, not definitive proof.
