# INC-016: Analytics ingestion lag

## Summary
A production incident affected `svc-analytics`.

## Root Cause
Analytics workers could not keep up with event ingestion.

## Resolution
Scale workers and batch event processing.

## Investigation Notes
Correlate logs, service metrics, deployment history, feature flags, database state and the
service-specific runbook. Historical incidents are supporting evidence, not definitive proof.
