# INC-006: Search Index Lag

## Summary
Search returned stale results.

## Root Cause
Indexer workers fell behind ingestion traffic.

## Evidence
- index age increased
- indexing queue depth increased
- query latency remained relatively normal

## Resolution
Increase indexer concurrency and add queue-depth alerting.
