# INC-023: API 429 surge

## Summary
A production incident affected `svc-rate-limit`.

## Root Cause
A hot tenant key caused uneven rate-limit counter load.

## Resolution
Shard hot keys and improve counter distribution.

## Investigation Notes
Correlate logs, service metrics, deployment history, feature flags, database state and the
service-specific runbook. Historical incidents are supporting evidence, not definitive proof.
