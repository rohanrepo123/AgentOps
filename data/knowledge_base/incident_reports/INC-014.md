# INC-014: Subscription state drift

## Summary
A production incident affected `svc-subscription`.

## Root Cause
A repeated webhook event applied a non-idempotent state transition.

## Resolution
Deduplicate webhook event IDs and make state transitions idempotent.

## Investigation Notes
Correlate logs, service metrics, deployment history, feature flags, database state and the
service-specific runbook. Historical incidents are supporting evidence, not definitive proof.
